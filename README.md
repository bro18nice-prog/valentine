# Valentine

A small interactive Valentine page built with HTML, CSS, and vanilla JavaScript.

## Try it

Open `index.html` in a browser. No build tools, package installation, or backend are needed.

The Yes button shows a message and a short heart animation. The No button moves around the viewport on pointer interaction or activation. Animation respects the reduced-motion preference; hearts are removed when the animation finishes.

## Files

- `index.html`: the complete page, styles, and interactions.
